Descarga de visitas

Modo seguro activado: para evitar el bloqueo de Chrome, finalizar una visita ya no genera el ZIP automáticamente. Primero se guarda; puedes descargar una copia ZIP segura por visita o solicitar el ZIP completo manualmente.

ZIP seguro (móvil): conserva todos los datos y fotografías para restaurar la visita, pero no genera los Word. ZIP completo + Word: úsalo preferentemente desde un ordenador. Mantén además tus copias anteriores.

Los ZIP descargados pueden recuperarse desde «Importar visitas / ZIP».

Fotografías y evidencias generales

Las fotos con GPS intentan primero leer las coordenadas incluidas en la propia fotografía y, si no existen, solicitan la ubicación actual del móvil. Si eliges «Elegir fotos ya geoetiquetadas», la aplicación intenta leer sus coordenadas EXIF pero no les añade el cuadradito sobreimpreso, para conservar el sello que ya trae la imagen. Si el navegador bloquea la ubicación, la fotografía se conserva igualmente y puedes pulsar «Actualizar GPS» después.

Informe final editable

Word para presentar: las imágenes se reducirán automáticamente solo en el DOCX descargado, sin modificar las fotos guardadas. Cada Word tendrá un límite de 9,5 MB (menos de los 10 MB permitidos). El ZIP de respaldo es independiente y puede pesar más.

Pulsa “Regenerar” para incorporar los últimos datos. Después puedes editar directamente cualquier texto o celda del informe antes de descargarlo.

Si editas el informe a mano y luego pulsas “Regenerar”, esas modificaciones manuales se sustituirán por los datos actuales de la visita.

Anexo fotográfico

Para evitar bloqueos en el móvil, el anexo no se carga automáticamente. Al mostrarlo o descargarlo, se incorporan también las fotografías añadidas después de la última edición (incluidas las ya geoetiquetadas). Puedes descargarlo sin tenerlo abierto o mostrarlo para editarlo.
